# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Added
- Initial release of Taurus Executor
- Remote command execution with real-time streaming output
- Interactive session support
- File upload and download capabilities
- mTLS security with certificate management
- Self-updating mechanism with zero-downtime
- Privileged execution support (sudo/su)
- Python SDK and CLI tools
- Prometheus metrics integration
- Cross-platform support (Linux, macOS)

### Changed
- Renamed from Orion Executor to Taurus Executor
