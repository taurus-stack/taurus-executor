# Taurus Executor 架构

## 概述

Taurus Executor 是一款基于 gRPC 构建的高性能、自动更新的远程命令执行系统。它支持在远程主机上安全、实时地执行命令，并支持交互式会话、文件传输和特权操作。

## 核心组件

### 1. gRPC 服务端 (`services/server.py`)

gRPC 服务端是执行器的主要入口点，它处理：

- **双向 TLS 认证**：用于安全的客户端-服务端通信
- **命令执行**：ExecuteCommand RPC 用于运行命令
- **会话管理**：CreateSession、ExecuteInSession、CloseSession RPC
- **文件传输**：UploadFile、DownloadFile RPC
- **健康检查**：HealthCheck RPC 用于监控
- **自动更新**：Update RPC 用于触发更新

### 2. 命令执行器 (`executors/command_executor.py`)

处理实际的命令执行：

- **进程创建**：使用 `subprocess.Popen` 创建进程
- **I/O 流式传输**：异步读取 stdout/stderr
- **信号处理**：正确将信号转发到子进程
- **超时管理**：命令超时后优雅终止
- **退出码追踪**：正确报告退出码和信号

### 3. 会话管理器 (`services/session_manager.py`)

管理交互式 Shell 会话：

- **会话创建**：创建持久的 Shell 会话
- **命令执行**：在会话上下文中执行命令
- **工作目录**：在多个命令间保持工作目录
- **环境变量**：保留环境变量
- **会话清理**：关闭会话时正确清理资源

### 4. TLS 管理器 (`infra/tls_manager.py`)

处理证书管理：

- **证书加载**：加载服务端/客户端证书和密钥
- **双向 TLS 配置**：为 gRPC 配置双向 TLS
- **CRL 检查**：证书吊销列表验证
- **证书生成**：证书生成的辅助函数

### 5. 状态管理器 (`infra/state_manager.py`)

持久化配置和状态：

- **配置存储**：存储执行器配置
- **状态持久化**：在重启后保持状态
- **原子写入**：确保状态文件的原子写入
- **迁移支持**：处理状态格式迁移

### 6. 自动更新器 (`infra/self_updater.py`)

管理零停机更新：

- **版本检查**：定期检查新版本
- **包下载**：下载新版本包
- **校验和验证**：SHA256 验证下载内容
- **优雅切换**：在停止旧版本前启动新版本
- **健康检查**：在切换前验证新版本
- **回滚支持**：失败时自动回滚

## 数据流

### 命令执行流程

```
1. 客户端发送 ExecuteCommand 请求
2. gRPC 服务端接收请求
3. 认证拦截器验证请求
4. 命令执行器创建子进程
5. 异步读取 I/O 流
6. 将 CommandResponse 事件流式返回
7. 进程退出，发送最终响应
```

### 会话流程

```
1. 客户端发送 CreateSession 请求
2. 会话管理器创建 Shell 会话
3. 将会话 ID 返回给客户端
4. 客户端发送 ExecuteInSession 请求
5. 在会话上下文中执行命令
6. 客户端发送 CloseSession 请求
7. 会话管理器清理资源
```

### 自动更新流程

```
1. 更新器检查新版本
2. 从服务端下载包
3. 验证 SHA256 校验和
4. 安装到新目录
5. 启动新版本进程
6. 对新进程进行健康检查
7. 如果健康则停止旧进程
8. 如果不健康则回滚
```

## 安全模型

### 认证

- **双向 TLS**：所有 gRPC 通信使用双向 TLS
- **基于票据的认证**：会话访问的临时票据
- **证书吊销**：对已吊销证书进行 CRL 检查

### 授权

- **基于角色的访问**：管理员、操作员、查看者角色
- **命令验证**：验证命令参数
- **权限检查**：检查文件系统权限

### 数据保护

- **加密传输**：所有数据通过 TLS 加密
- **安全密码处理**：安全传输密码
- **审计日志**：记录所有命令用于审计

| `LOG_FORMAT` | 日志格式（text/json） | `text` |

## Protocol Buffers

gRPC 服务定义在 `proto/executor/v1/command_service.proto` 中：

- **ClientService**：命令执行的主要服务
- **ExecuteCommand**：执行命令并流式输出
- **CreateSession**：创建交互式会话
- **ExecuteInSession**：在会话中执行命令
- **CloseSession**：关闭会话
- **UploadFile**：向主机上传文件
- **DownloadFile**：从主机下载文件
- **HealthCheck**：检查执行器健康状态
- **GetStatus**：获取系统状态

## 性能考量

- **异步 I/O**：所有 I/O 操作都是异步的
- **连接池**：gRPC 连接池提高效率
- **内存管理**：正确清理子进程资源
- **缓冲区管理**：I/O 流的高效缓冲区处理
- **进程隔离**：每个命令在隔离的进程中运行

## 错误处理

- **优雅降级**：系统在部分失败时继续运行
- **重试逻辑**：对瞬时失败自动重试
- **熔断器**：防止级联失败
- **健康监控**：持续健康检查
- **告警集成**：对关键失败发出告警
